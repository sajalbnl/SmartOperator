# Spindle Warmup

1. Check that the enclosure is clear and the spindle has no tool fitted.
2. Run 1,000 rpm for 5 minutes.
3. Run 3,000 rpm for 5 minutes.
4. Run 6,000 rpm for 5 minutes.
5. Listen for rumble or cyclic noise at each speed.
6. Stop and call maintenance if temperature or noise rises sharply.
