# Coolant Top-Up

1. Stop the cycle and allow return flow to settle for 2 minutes.
2. Read the tank level and refractometer concentration.
3. Premix concentrate with clean water to the posted shop ratio.
4. Add premix slowly at the tank fill point; do not add concentrate neat.
5. Run the pump for 3 minutes and recheck level and concentration.
6. Record litres added and the final reading.
