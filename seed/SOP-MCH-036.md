# Work Offset Verification

1. Confirm the fixture number and setup sheet match the loaded program.
2. Clean the datum face and probe stylus.
3. Probe X, Y, and Z datums in setup mode.
4. Compare the new values with the last approved setup; investigate any large shift.
5. Save values to the specified work offset only.
6. Dry-run the first tool above the stock before releasing production.
